# ⚔️ 極限倖存者：魔法割草大冒險 (Rogue Survivor)

一款純前端、零依賴、具備高打擊爽感的 **Roguelite 割草生存 HTML5 小遊戲**。

---

## 🌟 遊戲特色
- **純原生開發**：採用純原生 HTML5 Canvas、CSS3 與 JavaScript (ES6+)，完全**不依賴**任何外部第三方 CDN 或函式庫，支援 100% 離線遊玩。
- **純代碼合成音效**：內建 Web Audio API 音效合成引擎，打擊聲、升級音效、雷擊爆破全部動態合成，無需加載外部音檔。
- **自動瞄準施法**：玩家僅需專注走位，武器自動鎖定攻擊。
- **經典肉鴿三選一升級**：升級時暫停並彈出 3 張隨機天賦卡，自由構築流派（法球守護流、全屏雷擊流、爆炸火球流、極速風箏流）。
- **完整 HUD 與數值回饋**：經驗值條、即時傷害飄字、粒子特效、最高擊殺紀錄本地持久化（`localStorage`）。

## 🔮 奧術天賦流派

1. **🔮 奧術法球 (Arcane Orbit)**：
   - 環繞法師身周高速旋轉，對近身敵人造成連續碾壓傷害與微擊退。
2. **⚡ 連鎖閃電 (Chain Lightning)**：
   - 自動召喚天雷劈向隨機怪獸群，升級後可劈中多個目標。
3. **🔥 追蹤火球 (Homing Fireball)**：
   - 朝最近敵人射出火球，命中後引發大範圍群體爆炸。
4. **❄️ 冰霜新星 (Frost Nova)**：
   - 週期性向全屏釋放冰暴，凍結所有敵人數秒並造成傷害。
5. **👟 疾風之靴 (Fleet Boots)**：
   - 永久提升角色走位移動速度。
6. **💖 泰坦之心 (Titan Heart)**：
   - 立即回復 35 HP 並永久提升生命上限。

## 🚀 如何運行與部署

### 1. 本地直接執行
直接用瀏覽器（Chrome、Edge、Firefox 等）雙擊打開 `index.html` 即可立即開始遊玩！

### 2. 本地 HTTP 伺服器（推薦）
若有 Python 或 Node 環境，可使用任意微型伺服器：
```bash
# Python
python -m http.server 8080

# 或使用 npx serve
npx serve .
```
接著在瀏覽器打開 `http://localhost:8080`。

### 3. 發布至 GitHub Pages
1. 將此專案推送至 GitHub 倉庫。
2. 進入倉庫的 **Settings** ➔ **Pages**。
3. **Source** 選擇 `main` 分支並儲存。
4. 即可獲得專屬公開線上網址與好友分享遊玩！
